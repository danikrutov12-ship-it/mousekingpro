# 👑 Mouse King Pro

Десктопный ИИ-агент на моделях [Venice AI](https://venice.ai) для **Windows** и **Linux**:
чат с моделями (в том числе без цензуры), работа с проектами, файлами, архивами и кодом, терминал,
браузер, генерация и правка картинок, видео, голос, Telegram-бот, расписания и MCP-подключения.

## Установка

### Windows 10 / 11
1. Откройте [последний релиз](https://github.com/danikrutov12-ship-it/mousekingpro/releases/latest)
   и скачайте `Mouse-King-Pro-Setup-X.Y.Z.exe`.
2. Запустите его — программа установится сама (права администратора не нужны) и появится
   в меню «Пуск» и на рабочем столе. Ничего дополнительно ставить не нужно.
3. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите
   **Подробнее → Выполнить в любом случае** (у программы пока нет платной цифровой подписи).

### Linux (AppImage)
Скачайте `Mouse-King-Pro-X.Y.Z.AppImage` из релиза, затем:
```bash
chmod +x Mouse-King-Pro-*.AppImage
./Mouse-King-Pro-*.AppImage
```
В настройках → «Оформление» → «Mouse King Pro в меню приложений» можно добавить значок в меню.

### Linux (из исходников)
```bash
git clone https://github.com/danikrutov12-ship-it/mousekingpro.git
cd mousekingpro
./run.sh          # при первом запуске установит зависимости и соберёт программу (нужен Node.js 22+)
```
На Ubuntu 24.04+ один раз выполните `sudo ./setup-sandbox.sh` (разрешение песочницы Electron).

## Обновления
Программа сама проверяет новые версии при запуске и каждые 6 часов. Когда выходит обновление,
внизу слева появляется плашка **«Доступно обновление» → «Скачать» → «Перезапустить и обновить»**.
Вручную: Настройки → Оформление → «Проверить обновления».

| Как установлено | Как обновляется |
|---|---|
| Установщик Windows | скачивается новый установщик и ставится поверх, данные сохраняются |
| AppImage | заменяется файл AppImage |
| Из исходников (`git clone`) | `git pull` + пересборка |

## Где хранятся данные
API-ключ, токены и пароли хранятся **только на вашем компьютере** (зашифрованы системным хранилищем)
и никогда не попадают в репозиторий.

| | Windows | Linux |
|---|---|---|
| Настройки, чаты, галерея | `%APPDATA%\Mouse King Pro` | `~/.local/share/venice-agent` |
| Файлы проектов | `C:\Users\<имя>\MouseKingPro` | `~/VeniceAgent` или `~/MouseKingPro` |

## Для разработки
```bash
cd desktop
npm install
npm run dev         # запуск с горячей перезагрузкой
npm run typecheck   # проверка типов
npm run dist        # AppImage в desktop/dist
npm run dist:win    # установщик Windows (лучше собирать в GitHub Actions)
```

Выпуск версии: `./release.sh 2.2.0 "Что нового"` — ставит тег, GitHub Actions собирает
Windows- и Linux-версии и публикует релиз, после чего все установленные программы предложат обновиться.

Структура: `desktop/` — программа (Electron + React + TypeScript), `legacy-qt/` — первая версия на Python/Qt (не развивается).
